    17→## Game Rules Summary (implemented across tasks)
    18→
    19→- ALL cards are yellow. Match by NUMBER value only, or play an ACTION card (action cards are always playable; if the top card is an action card, any number may be played).
    20→- Deck: numbers 0–9 ×3, SKIP ×4, REVERSE ×4, +2 ×4, MEGA +4 ×3, SWAP ×3, WILDFIRE ×3, SHIELD ×3, BATTLE ×3 (57 cards).
    21→- SKIP / REVERSE: in this 1v1, the player who played it goes again.
    22→- +2 / MEGA +4: opponent draws (2/4) and is skipped → attacker goes again.
    23→- SWAP: exchange hands. WILDFIRE: everyone draws 1. SHIELD: blocks the NEXT forced draw (from +2/+4/BATTLE penalty/WILDFIRE/Chaos draws), then breaks.
    24→- BATTLE: 3-second mash mini-game — loser draws 4, tie → both draw 2.
    25→- Chaos Frenzy Meter: +8% per card played; at 100% a random chaos event fires (DRAW RAIN = everyone draws 2 / DECK EXPLOSION = reshuffle / TOP CARD MORPH) with screen shake + banner.
    26→- Win: empty your hand first. Stats (wins/losses/streaks/battles won) persist in localStorage.
    27→- Difficulty affects AI reaction time, aggression, battle mash rate: EASY / CHAOTIC / INSANE.

   102→### Rules modal content (Task 2-a must include ALL of this):
   103→1. **THE TWIST** — Every card is YELLOW. Forget colors — match the NUMBER on the discard pile, or slam an ACTION card at any time.
   104→2. **NUMBER CARDS 0–9** — Play a number only if it matches the top card's number. If the top card is an action card, any number is legal.
   105→3. **ACTION CARDS** (always playable) — with mini chips (small bordered squares + lucide icon):
   106→   - SKIP (Ban icon): opponent loses their turn.
   107→   - REVERSE (RefreshCcw icon): the turn bounces back — you go again.
   108→   - +2: opponent draws 2 and is skipped.
   109→   - MEGA +4: opponent draws 4 and is skipped. Devastating.
   110→   - SWAP (ArrowLeftRight icon): instantly trade hands with the CPU. Brutal when you're losing.
   111→   - WILDFIRE (Flame icon): EVERYONE draws 1 card.
   112→   - SHIELD (Shield icon): raises a barrier that blocks the next time you're forced to draw (+2, +4, battle penalties, wildfire, chaos draws) — then it breaks.
   113→   - BATTLE (Swords icon): triggers the SUDDEN CARD BATTLE mini-game.
   114→4. **SUDDEN CARD BATTLE** — 3 seconds of button-mashing fury. Highest score wins; the loser draws 4 cards. Ties hurt everyone.
   115→5. **CHAOS FRENZY METER** — every card played charges the meter. At 100% a random CHAOS EVENT erupts: DRAW RAIN (everyone draws 2), DECK EXPLOSION (reshuffle), or TOP CARD MORPH.
   116→6. **WINNING** — first to empty their hand wins. Shout UNO when you hold one card.
   117→7. **DIFFICULTY** — EASY: sleepy & sloppy. CHAOTIC: unpredictable action-card spam. INSANE: fast, tactical, merciless.

   279→## PvP GAME-RULES SPEC FOR THE SERVER (Task 2-a) — mirrors the CPU reducer exactly
   280→
   281→State per room: `gameId, deck, discard, hands[2], turn, frenzy, chaosPending, shields[2], pendingDrawn[2], phase ('waiting'|'playing'|'battle'|'game-over'), battle {phase:'ready'|'mash'|'result', msLeft, scores[2], winner, initiator}, gameOver {winner, reason}, log (cap 80, LogEntry with server-assigned numeric ids), logSeq, bannerSeq, shakeSeq, chaosBanner`.
   282→
   283→- NEW MATCH: `createInitialGame()` from engine → playerHand→seat0, aiHand→seat1, first discard = a number card. Random seat goes first. Log `"{nameA} VS {nameB} — {name} GOES FIRST!"`. gameId += 1.
   284→- PLAY validation: phase 'playing', turn === seat, card in that seat's hand, if `pendingDrawn[seat]` set then ONLY that card may be played, `isPlayable(card, top)` from engine.
   285→- playCard effects (all mirror `use-uno-game.ts` reducer): log `"{name} plays {cardName}!"` + sound from PVP_CARD_SOUNDS; frenzy += 8 (>=100 → subtract 100, chaosPending = true); UNO shout log at 1 card left; WIN check BEFORE effects → phase 'game-over', winner, reason 'empty-hand', log + sound win/lose; number → pass turn to opponent; skip/reverse → same player goes again (log); draw2/draw4 → applyPenalty(opponent) then same player goes again; swap → swap hands, pass turn; wildfire → both draw 1 (shield applies), pass turn; shield → set that seat's shield, pass turn; battle → phase 'battle', battle {phase:'ready', msLeft:3000, scores:[0,0], winner:null, initiator:seat}.
   286→- applyPenalty(seat, count): if shields[seat] → consume shield, log "SHIELD absorbs the attack — no cards drawn!" (kind 'shield', sound 'shield'), return; else draw up to count cards into hand (drawCard reshuffles discard into deck when deck runs empty; if truly no cards → log "every card is in play!"); log `"{name} draws N cards!"` kind 'penalty' sound 'penalty'.
   287→- DRAW validation: phase 'playing', turn === seat, no pendingDrawn[seat]. Card = drawCard(); if none → log "no cards left to draw — turn passes", pass turn. Else push to hand, pendingDrawn[seat] = card, log `"{name} draws a card."` sound 'draw'. If NOT playable → schedule auto-keep after 1300ms (guard: pendingDrawn[seat] still that card id). If playable the player chooses.
   288→- KEEP: clear pendingDrawn, log `"{name} keeps the drawn card."` (or on auto-pass: "No match — turn passes."), pass turn to opponent.
   289→- CHAOS: resolve only when `phase === 'playing'` (defer while battle/game-over — check after every mutation + when battle closes). pickChaosEvent() from engine; banner (bannerSeq++, chaosBanner set, shakeSeq++), log kind 'chaos' sound 'chaos'. draw-rain → both seats applyPenalty(2); reshuffle → deck = shuffle(deck + discard minus top), discard = [top], log; morph → random card from deck (fallback makeRandomNumberCard), remove from deck, old top pushed into deck, new top = morph, log "The top card morphs into X!".
   290→- BATTLE lifecycle (server timers, guard every callback): ready 900ms → mash; mash interval 100ms → msLeft -= 100 (clamp 0), broadcast; at 0 → winner = higher score ('tie' equal), phase 'result', log + applyPenalty (loser 4 / both 2), stats-ish log lines like the CPU game ("{name} WINS THE BATTLE a—b!"); result 1700ms → battle = null, phase 'playing', turn = opponent of initiator, then tryResolveChaos.
   291→- MASH: phase 'battle' && battle.phase === 'mash' → scores[seat] += 1.
   292→- REMATCH: phase 'game-over' && both seats connected → newMatch() (logs "REMATCH!").
   293→- LEAVE / DISCONNECT: if phase 'waiting' → destroy room. Else: clear timers, gameOver {winner: other seat, reason 'forfeit'}, phase 'game-over', log, sockets[seat] = null, broadcast to remaining. When last socket leaves → destroy room.
   294→- Broadcast: after every state change, emit `room:state` (PvpRoomView) to EACH connected socket, personalized: hand = hands[seat], opponentCardCount = other hand length, pendingDrawn = that seat's own pending card, opponentDeciding = other seat's pendingDrawn !== null, opponentConnected = other socket present.
   295→- Room codes: 4 chars from `ABCDEFGHJKMNPQRSTUVWXYZ23456789` (no I L O 0 1). Names: trim, collapse spaces, max 12 chars, default "PLAYER 1" / "PLAYER 2". Ack errors: 'not-found', 'full', 'invalid-name', 'invalid-code'.
